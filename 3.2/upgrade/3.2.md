# Guia de atualização para 3.2

- A versão 3.2 alterou principalmente a versão mínima do `PHP` para `8.2`.
- Componentes `symfony/*` atualizados para suportar `^6.0 || ^7.0`.
- `phpunit/phpunit` atualizado para `^11.0`.

## Mudanças incompatíveis

1. O componente `async-queue` renomeou `JobInterface::getQueueName()` para `getPoolName()`.

```php
<?php
// Antes da mudança
class CustomJob extends \Hyperf\AsyncQueue\Job
{
    public function getQueueName(): string
    {
        return 'custom';
    }
}

// Depois da mudança
class CustomJob extends \Hyperf\AsyncQueue\Job
{
    public function getPoolName(): string
    {
        return 'custom';
    }
}
```

2. A estrutura de configuração do `logger` foi alterada. Consulte [#7563](https://github.com/hyperf/hyperf/pull/7563).

3. A estrutura de configuração do `cache` foi alterada. Consulte [#7594](https://github.com/hyperf/hyperf/pull/7594).

4. Ao usar `swow`, é necessário adicionar a dependência de response emitter.

```php
<?php
// config/autoload/dependencies.php

use Hyperf\Contract\ResponseEmitterInterface;
use Hyperf\Engine\ResponseEmitter;

return [
    ResponseEmitterInterface::class => ResponseEmitter::class,
];
```

## Atualização de dependências

- Atualize a versão do php para `>=8.2`.
- Atualize `elasticsearch/elasticsearch` para `^8.0 || ^9.0`.
- Atualize `nikic/php-parser` para `5.6`.
- Atualize os componentes `symfony/*` para `^6.0 || ^7.0`.
- Atualize `phpunit/phpunit` para `^11.0`.
- Atualize `google/protobuf` para `^3.6.1 || ^4.2`.
- Atualize `guzzlehttp/guzzle` para `^7.0`.

## Atenção

Se você já atualizou para o PHP 8.4, os métodos `fgetcsv` e `fputcsv` agora exigem que se forneça um valor padrão para o parâmetro `escape`.

```php
fputcsv($fp, $fields, escape: '');
fgetcsv($fp, escape: '');
```
