# Guia de atualização 3.1

- A versão 3.1 alterou principalmente a versão mínima do `PHP` para `8.1` e a versão mínima do `Swoole` para `5.0`
- Introduziu o framework de testes `Pest`
- Adicionou `hyperf/helper`; as `funções auxiliares sem namespace` que existiam em `Hyperf\Utils` foram migradas para `hyperf/helper`
- Alterou a forma de carregamento de arquivos de configuração multinível do `hyperf/config`, passando a suportar a sintaxe `.`, como `config('a.c')`

## Mudanças no pacote Utils

As funções auxiliares do pacote utils original não tinham namespace e podiam conflitar com funções de outros pacotes composer; na 3.1 elas foram removidas e substituídas.

Há duas formas de tratar isso:

1. Se você confirmar que o programa não carrega pacotes que causariam conflito de funções, pode simplesmente instalar `hyperf/helper`; o pacote `helper` fornece as funções auxiliares sem namespace, iguais às do `utils` original
2. Adicione namespace nos locais onde as funções auxiliares são chamadas; você pode usar o `rector` para refatorar, consulte a [documentação de refatoração](https://github.com/orgs/hyperf/discussions/5635)

## Mudança na forma de carregamento dos arquivos de configuração

Na 3.0, a configuração existia tendo o `nome do arquivo de configuração` como chave, enquanto na 3.1, a forma de carregamento de arquivos de configuração multinível do `hyperf/config` passa a ter `diretório relativo.nome do arquivo de configuração` como chave.

Suporta a sintaxe `.`, como `config('a.c')`.

Com isso, é preciso atenção ao tratamento das duas situações abaixo em projetos antigos

- Projetos 3.0 que criaram subdiretórios em `config/autoload`, como `config/autoload/sub/a.php`, precisam alterar o `config('a')` original para `config('sub.a')`.
- Projetos 3.0 cujo nome do arquivo de configuração contém `.`, como `config/autoload/a.b.php`, retornarão a seguinte estrutura ao usar `config('a')`; se você também tiver o arquivo de configuração `config/autoload/a.php`, obterá o resultado com os itens de configuração mesclados.

```php
return [
    'Item de configuração em a.php' => 'Valor de configuração em a.php',
    'b' => [
        'Item de configuração em a.b.php' => 'Valor de configuração em a.b.php',
    ]
];
```

## Outras alterações

1. A partir da versão v3.1, o componente `hyperf/metirc` não instala mais a dependência `prometheus` por padrão. Portanto, desenvolvedores que precisam usar o mecanismo `prometheus` devem executar o seguinte comando para carregar a dependência:

```bash
composer require promphp/prometheus_client_php
```

2. A funcionalidade `withHeaders` de `Request` e `Response` sofreu alterações

Versões anteriores à v3.1 preservavam os dados originais, de forma semelhante ao `array_merge` dos dados originais; a partir da v3.1, todos os `headers` são diretamente substituídos

```php
<?php
// Antes da v3.1
$request->withHeader('foo', 1)->withHeader('bar', 2); // ['foo' => [1], 'bar' => [2]]
$request->withHeader('foo', 1)->withHeader('foo', 2); // ['foo' => [2]]
$request->withAddedHeader('foo', 1)->withAddedHeader('foo', 2); // ['foo' => [1, 2]]

$request->withHeaders(['foo' => 1])->withHeaders(['bar' => 2]); // ['foo' => [1], 'bar' => [2]]

// Depois da v3.1
$request->withHeader('foo', 1)->withHeader('bar', 2); // ['foo' => [1], 'bar' => [2]]
$request->withHeader('foo', 1)->withHeader('foo', 2); // ['foo' => [2]]
$request->withAddedHeader('foo', 1)->withAddedHeader('foo', 2); // ['foo' => [1, 2]]

$request->withHeaders(['foo' => 1])->withHeaders(['bar' => 2]); // ['bar' => [2]]

$request->setHeader('foo', 1)->setHeader('bar', 2); // ['foo' => [1], 'bar' => [2]]
$request->setHeader('foo', 1)->setHeader('foo', 2); // ['foo' => [2]]
$request->addHeader('foo', 1)->addHeader('foo', 2); // ['foo' => [1, 2]]

$request->setHeaders(['foo' => 1])->setHeaders(['bar' => 2]); // ['bar' => [2]]

```
3. O valor de retorno do método `consumeMessage` do consumidor `AMQP` foi ajustado para o enum `Result`

```php
<?php
// Antes da v3.1
public function consumeMessage($data, AMQPMessage $message): string
{
    return Result::ACK;
}
// Depois da v3.1
public function consumeMessage($data, AMQPMessage $message): Result
{
    return Result::ACK;
}
```
