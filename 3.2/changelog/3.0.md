## BC breaks

- O framework removeu o uso de `@Annotation` e passou a usar integralmente a anotação nativa do `PHP8`, `Attribute`. Antes de atualizar o framework, certifique-se de que todas as substituições para a anotação nativa do PHP8 já foram feitas.

Fornecemos um script que facilita a substituição de `Doctrine Annotations` por `PHP8 Attributes`.

!> Nota: o script a seguir só pode ser executado na versão 2.2 do framework

```shell
composer require hyperf/code-generator
php bin/hyperf.php code:generate -D app
```

- Script de atualização de modelos

> Como a classe base de modelos passou a ter restrições de tipo, você precisa usar o script a seguir para atualizar todos os modelos para a nova forma de escrita.

```shell
composer require hyperf/code-generator
php vendor/bin/regenerate-models.php $PWD/app/Model
```

- O framework adicionou muitas restrições de tipo, portanto, ao atualizar da versão `2.2` para a `3.0`, você precisa chamar o script de análise estática para verificar e garantir que tudo funcione normalmente.

```shell
composer analysis
```

- O framework modificou o código de retorno HTTP dos serviços `gRPC` com base no padrão `gRPC`.
