# Registro de atualização de versões

# v2.1.23 - 2021-07-12

## Otimização

- [#3787](https://github.com/hyperf/hyperf/pull/3787) Otimiza o serviço `JSON RPC`, inicializando prioritariamente o `PSR Response`, para evitar o problema de não ser possível obter o `Response` do contexto após a falha na inicialização do `PSR Request`.

# v2.1.22 - 2021-06-28

- [#3724](https://github.com/hyperf/hyperf/pull/3724) Corrige o problema de ser possível usar a regra `RequiredIf` para gerar uma pequena cadeia de ferramentas destinada a vulnerabilidades de desserialização.

## Correções

- [#3721](https://github.com/hyperf/hyperf/pull/3721) Corrige o problema de julgamento incorreto nas regras de validação `in` e `not in`; por exemplo, quando a regra é `in:00`, `0` não deveria ser permitido passar.

# v2.1.0 - 2020-12-28

## Atualização de dependências

- Atualiza a versão do `php` para `>=7.3`.
- Atualiza a versão do componente `phpunit/phpunit` para `^9.0`.
- Atualiza a versão do componente `guzzlehttp/guzzle` para `^6.0|^7.0`.
- Atualiza a versão do componente `vlucas/phpdotenv` para `^5.0`.
- Atualiza a versão do componente `endclothing/prometheus_client_php` para `^1.0`.
- Atualiza a versão do componente `twig/twig` para `^3.0`.
- Atualiza a versão do componente `jcchavezs/zipkin-opentracing` para `^0.2.0`.
- Atualiza a versão do componente `doctrine/dbal` para `^3.0`.
- Atualiza a versão do componente `league/flysystem` para `^1.0|^2.0`.

## Remoção

- Remove a variável de membro obsoleta `$name` de `Hyperf\Amqp\Builder`.
- Remove o método obsoleto `consume()` de `Hyperf\Amqp\Message\ConsumerMessageInterface`.
- Remove a variável de membro obsoleta `$running` de `Hyperf\AsyncQueue\Driver\Driver`.
- Remove o método obsoleto `parseParameters()` de `Hyperf\HttpServer\CoreMiddleware`.
- Remove as constantes obsoletas `ON_WORKER_START` e `ON_WORKER_EXIT` de `Hyperf\Utils\Coordinator\Constants`.
- Remove o método obsoleto `get()` de `Hyperf\Utils\Coordinator`.
- Remove o arquivo de configuração `rate-limit.php`; use `rate_limit.php`.
- Remove a classe inútil `Hyperf\Resource\Response\ResponseEmitter`.
- Remove o componente `hyperf/paginator` das dependências de `hyperf/database`.
- Remove o método `stats()` de `Hyperf\Utils\Coroutine\Concurrent`.

## Alterações

- O método `Hyperf\Utils\Coroutine::parentId` retorna o ID da corrotina pai
  * Se estiver na corrotina principal, retorna 0.
  * Se for usado em um ambiente sem corrotina, lança a exceção `RunningInNonCoroutineException`.
  * Se o ambiente de corrotina já tiver sido destruído, lança a exceção `CoroutineDestroyedException`.

- A classe `Hyperf\Guzzle\CoroutineHandler`
  * Removeu o método `execute()`.
  * O método `initHeaders()` passará a retornar a lista de Header inicializada, em vez de atribuir diretamente `$headers` ao cliente.
  * Removeu o método `checkStatusCode()`.

- [#2720](https://github.com/hyperf/hyperf/pull/2720) Não define mais `data_type` no método `PDOStatement::bindValue()`, evitando o problema de o índice não ser encontrado ao usar inteiros em índices de string.
- [#2871](https://github.com/hyperf/hyperf/pull/2871) Ao obter dados de `StreamInterface`, usa `(string) $body` em vez de `$body->getContents()`, pois o método `getContents()` retorna apenas os dados restantes, e não todos os dados.
- [#2909](https://github.com/hyperf/hyperf/pull/2909) Permite definir middlewares duplicados.
- [#2935](https://github.com/hyperf/hyperf/pull/2935) Altera as regras padrão do `Exception Formatter`.
- [#2979](https://github.com/hyperf/hyperf/pull/2979) O comando `gen:model` não converte mais automaticamente o formato `decimal` em `float`.

## Depreciação futura

- A classe `Hyperf\AsyncQueue\Signal\DriverStopHandler` será depreciada na versão `v2.2`; use `Hyperf\Process\Handler\ProcessStopHandler` em seu lugar.
- A classe `Hyperf\Server\SwooleEvent` será depreciada na versão `v3.0`; use `Hyperf\Server\Event` em seu lugar.
