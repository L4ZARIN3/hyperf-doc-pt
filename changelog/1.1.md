# v1.1.32 - 2020-05-21

## Correções

- [#1734](https://github.com/hyperf/hyperf/pull/1734) Corrige o problema da consulta polimórfica de modelos em que o SQL era consultado mesmo quando a relação estava vazia;
- [#1739](https://github.com/hyperf/hyperf/pull/1739) Corrige o erro de operação bit a bit no HOOK de OSS do componente `hyperf/filesystem`, que fazia com que a avaliação de `resource` fosse imprecisa;
- [#1743](https://github.com/hyperf/hyperf/pull/1743) Corrige o valor incorreto do campo `refId` no `grafana.json`;
- [#1748](https://github.com/hyperf/hyperf/pull/1748) Corrige o problema em que a configuração `concurrent.limit` correspondente não tinha efeito no componente `hyperf/amqp` ao usar outro pool de conexões;
- [#1750](https://github.com/hyperf/hyperf/pull/1750) Corrige o problema do componente de pool de conexões em que a falha ao fechar a conexão causava contagem incorreta;
- [#1754](https://github.com/hyperf/hyperf/pull/1754) Corrige o aviso de inicialização do serviço BASE Server, que não considerava o caso de serviços UDP;
- [#1764](https://github.com/hyperf/hyperf/pull/1764) Corrige o BUG em que o validador `datetime` falhava quando o valor de data era nulo;
- [#1769](https://github.com/hyperf/hyperf/pull/1769) Corrige o problema do componente `hyperf/socketio-server` em que o cliente reportava um erro Notice ao inicializar a operação de desconexão;

## Novidades

- [#1724](https://github.com/hyperf/hyperf/pull/1724) Adiciona os métodos de modelo `Model::orWhereHasMorph`, `Model::whereDoesntHaveMorph` e `Model::orWhereDoesntHaveMorph`;
- [#1741](https://github.com/hyperf/hyperf/pull/1741) Adiciona o método `Hyperf\Command\Command::choiceMultiple(): array`, pois o tipo de retorno do método `choice` é `string`, portanto mesmo definindo o parâmetro `$multiple` não era possível tratar múltiplas seleções;
- [#1742](https://github.com/hyperf/hyperf/pull/1742) Adiciona o recurso de conversor de tipo personalizado para modelos;
  - Adiciona as interfaces `Castable`, `CastsAttributes` e `CastsInboundAttributes`;
  - Adiciona o método `Model\Builder::withCasts`;
  - Adiciona os métodos `Model::loadMorph`, `Model::loadMorphCount` e `Model::syncAttributes`;

- [#401](https://github.com/hyperf/hyperf/pull/401) Adiciona o objeto `Hyperf\HttpServer\Router\Dispatched` para armazenar as informações da rota resolvida; a resolução ocorre antes dos middlewares do usuário para uso posterior e, ao mesmo tempo, corrige o problema de falha do middleware quando a rota possui parâmetros;
- [#402](https://github.com/hyperf/hyperf/pull/402) Adiciona a anotação `@AsyncQueueMessage`; ao defini-la em um método, indica que a lógica real de execução desse método é enviada para a fila Async-Queue consumir;
- [#418](https://github.com/hyperf/hyperf/pull/418) Permite enviar mensagens WebSocket para qualquer fd, mesmo que o processo Worker atual não possua o fd correspondente; o framework realiza automaticamente a comunicação entre processos para efetuar o envio;
- [#420](https://github.com/hyperf/hyperf/pull/420) Adiciona um novo mecanismo de eventos aos modelos de banco de dados que, em conjunto com o despachante de eventos PSR-15, permite definir Listeners de forma desacoplada para escutar eventos de modelos;
- [#429](https://github.com/hyperf/hyperf/pull/429) [#643](https://github.com/hyperf/hyperf/pull/643) Adiciona o componente de validação de formulários Validation, derivado do componente [illuminate/validation](https://github.com/illuminate/validation); agradecemos à equipe de desenvolvimento do Laravel por fornecer um componente de validação tão útil;
- [#441](https://github.com/hyperf/hyperf/pull/441) Fecha automaticamente conexões ociosas do Redis quando elas estão em baixa frequência de uso;
- [#478](https://github.com/hyperf/hyperf/pull/441) Melhor adaptação ao protocolo OpenTracing e também ao [Jaeger](https://www.jaegertracing.io/), um excelente sistema open source de rastreamento distribuído de cadeias de chamadas ponta a ponta;
- [#500](https://github.com/hyperf/hyperf/pull/499) Adiciona suporte a chamadas encadeadas de métodos em `Hyperf\HttpServer\Contract\ResponseInterface`, resolvendo o problema de não ser possível chamar o método original após chamar um método do proxy;
- [#523](https://github.com/hyperf/hyperf/pull/523) Adiciona a opção `table-mapping` ao comando `gen:model`;
- [#555](https://github.com/hyperf/hyperf/pull/555) Adiciona a função global `swoole_hook_flags` para obter o nível de Runtime Hook definido pela constante `SWOOLE_HOOK_FLAGS`; você pode definir essa constante em `bin/hyperf.php` por meio de `! defined('SWOOLE_HOOK_FLAGS') && define('SWOOLE_HOOK_FLAGS', SWOOLE_HOOK_ALL);`, ou seja, o nível de Runtime Hook;
- [#596](https://github.com/hyperf/hyperf/pull/596) Adiciona o parâmetro `required` à anotação `@Inject`; quando você define `@Inject(required=false)` em uma propriedade de membro, se a dependência não existir, não será lançada a exceção `Hyperf\Di\Exception\NotFoundException`, e sim injetado o valor padrão `null`; o valor padrão do parâmetro `required` é `true`; no caso de injeção pelo construtor, você pode atingir o mesmo objetivo definindo o parâmetro do construtor como `nullable`;
- [#597](https://github.com/hyperf/hyperf/pull/597) Adiciona `Concurrent` aos consumidores do componente AsyncQueue para controlar a taxa de consumo;
- [#599](https://github.com/hyperf/hyperf/pull/599) Adiciona aos consumidores do componente AsyncQueue o recurso de definir o tempo de espera para nova tentativa da mensagem conforme o número atual de tentativas, permitindo configurar esperas escalonadas para as mensagens;
- [#619](https://github.com/hyperf/hyperf/pull/619) Adiciona a classe HandlerStackFactory ao cliente Guzzle, para criar um HandlerStack com mais facilidade;
- [#620](https://github.com/hyperf/hyperf/pull/620) Adiciona o mecanismo de reinicialização automática aos consumidores do componente AsyncQueue;
- [#629](https://github.com/hyperf/hyperf/pull/629) Permite definir as configurações `clientIp`, `pullTimeout` e `intervalTimeout` do cliente Apollo por meio de arquivo de configuração;
- [#647](https://github.com/hyperf/hyperf/pull/647) Adiciona automaticamente `eof` ao TCP Response conforme a configuração do server;
- [#648](https://github.com/hyperf/hyperf/pull/648) Adiciona o tipo de retorno `nack` ao AMQP Consumer; quando a lógica de consumo retorna `Hyperf\Amqp\Result::NACK`, o consumidor abstrato responde à mensagem com o método `basic_nack`;
- [#654](https://github.com/hyperf/hyperf/pull/654) Adiciona o callback padrão de todos os Swoole Events e os eventos Hyperf correspondentes;

## Alterações

- [#437](https://github.com/hyperf/hyperf/pull/437) `Hyperf\Testing\Client` não lança mais a exceção diretamente ao encontrá-la, encaminhando-a ao fluxo do ExceptionHandler;
- [#463](https://github.com/hyperf/hyperf/pull/463) Simplifica o arquivo `container.php` e otimiza o mecanismo de cache de anotações;

O novo conteúdo do arquivo config/container.php é o seguinte:

```php
<?php

use Hyperf\Di\Container;
use Hyperf\Di\Definition\DefinitionSourceFactory;
use Hyperf\Context\ApplicationContext;

$container = new Container((new DefinitionSourceFactory(true))());

if (! $container instanceof \Psr\Container\ContainerInterface) {
    throw new RuntimeException('The dependency injection container is invalid.');
}
return ApplicationContext::setContainer($container);
```

- [#486](https://github.com/hyperf/hyperf/pull/486) O método `getParsedBody` de `Hyperf\HttpMessage\Server\Request` agora consegue tratar diretamente dados no formato JSON;
- [#523](https://github.com/hyperf/hyperf/pull/523) Ajusta o nome da classe de modelo gerada pelo comando `gen:model` para o singular por padrão; se o nome da tabela estiver no plural, o nome da classe gerada será no singular;
- [#614](https://github.com/hyperf/hyperf/pull/614) [#617](https://github.com/hyperf/hyperf/pull/617) Ajusta a estrutura da classe ConfigProvider e também move o arquivo `config/dependencies.php` para `config/autoload/dependencies.php`, removendo a camada `dependencies` da estrutura do arquivo; a partir de então, você também pode escrever a configuração `dependencies` no arquivo `config/config.php`;

Mudanças na estrutura de dados dentro do Config Provider:
Antes:

```php
'scan' => [
    'paths' => [
        __DIR__,
    ],
    'collectors' => [],
],
```

Agora:

```php
'annotations' => [
    'scan' => [
        'paths' => [
            __DIR__,
        ],
        'collectors' => [],
    ],
],
```

> Adiciona uma camada annotations, ficando assim consistente com a estrutura do arquivo de configuração, sem mais exceções

- [#630](https://github.com/hyperf/hyperf/pull/630) Altera o modo de instanciação da classe `Hyperf\HttpServer\CoreMiddleware`, usando `make()` em vez de `new`;
- [#631](https://github.com/hyperf/hyperf/pull/631) Altera o modo de instanciação do AMQP Consumer, usando `make()` em vez de `new`;
- [#637](https://github.com/hyperf/hyperf/pull/637) Ajusta a restrição de tipo do primeiro parâmetro de `Hyperf\Contract\OnMessageInterface` e `Hyperf\Contract\OnOpenInterface`, usando `Swoole\WebSocket\Server` em vez de `Swoole\Server`;
- [#638](https://github.com/hyperf/hyperf/pull/638) Renomeia o comando `db:model` para `gen:model` e adiciona um Visitor para otimizar a criação da propriedade de membro `$connection`; se o valor da propriedade `$connection` da classe de modelo a ser criada for igual ao da classe pai herdada, a classe de modelo criada não incluirá essa propriedade;

## Remoção

- [#401](https://github.com/hyperf/hyperf/pull/401) Remove as classes `Hyperf\JsonRpc\HttpServerFactory`, `Hyperf\HttpServer\ServerFactory` e `Hyperf\GrpcServer\ServerFactory`;
- [#402](https://github.com/hyperf/hyperf/pull/402) Remove o método obsoleto `AsyncQueue::delay`;
- [#563](https://github.com/hyperf/hyperf/pull/563) Remove a constante obsoleta `Hyperf\Server\ServerInterface::SERVER_TCP`, substituída por `Hyperf\Server\ServerInterface::SERVER_BASE`;
- [#602](https://github.com/hyperf/hyperf/pull/602) Remove o parâmetro `timeout` de `Hyperf\Utils\Coroutine\Concurrent`;
- [#612](https://github.com/hyperf/hyperf/pull/612) Remove a variável `$url` não utilizada no RingPHP Handler;
- [#616](https://github.com/hyperf/hyperf/pull/616) [#618](https://github.com/hyperf/hyperf/pull/618) Remove alguns códigos inúteis do Guzzle;

## Otimizações

- [#644](https://github.com/hyperf/hyperf/pull/644) Otimiza o fluxo de varredura de anotações, separando a varredura em duas partes, `app` e `vendor`, reduzindo bastante o tempo de varredura do usuário;
- [#653](https://github.com/hyperf/hyperf/pull/653) Otimiza a lógica de detecção do shortname do Swoole; a lógica atual é mais aderente aos cenários reais de configuração do Swoole e não exige mais que `swoole.use_shortname = "Off"` para passar na detecção;

## Correções

- [#448](https://github.com/hyperf/hyperf/pull/448) Corrige o problema em que o TCP Server podia não iniciar quando existiam HTTP Server ou WebSocket Server;
- [#623](https://github.com/hyperf/hyperf/pull/623) Corrige o problema em que, ao passar um valor `null` para o parâmetro de um método da classe proxy, o método ainda obtinha o valor padrão do método;
