# v3.2.0 - 2026-06-07

## Alterações incompatíveis

1. Alterações incompatíveis do componente Carbon
    - `Carbon::createFromTimestamp()` não lê mais o fuso horário padrão por meio de `date_default_timezone_get()` no `v3.0`.
    - Por padrão, `Carbon::diffInDays()` não retorna mais o valor absoluto. Use o parâmetro `$absolute` para controlar se o resultado é o valor absoluto.

2. [#7625](https://github.com/hyperf/hyperf/pull/7625) Para consistência de terminologia, renomeia `JobInterface::getQueueName()` do componente async-queue para `getPoolName()`.

```php
<?php
// Antes da alteração
class CustomJob extends \Hyperf\AsyncQueue\Job
{
    public function getQueueName(): string
    {
        return 'custom';
    }
}

// Após a alteração
class CustomJob extends \Hyperf\AsyncQueue\Job
{
    public function getPoolName(): string
    {
        return 'custom';
    }
}
```

```php
<?php

use Carbon\Carbon;

$t = time();

# Uso incompatível
Carbon::createFromTimestamp($t, date_default_timezone_get());

# Uso correto
Carbon::createFromTimestamp($t, date_default_timezone_get());
```

3. A estrutura de configuração do `logger` foi alterada. Consulte [#7563](https://github.com/hyperf/hyperf/pull/7563).

```php
<?php

// Antes da alteração
return [
    'default' => [
        'driver' => 'daily',
        'path' => BASE_PATH . '/runtime/logs/hyperf.log',
        'level' => env('LOG_LEVEL', 'debug'),
        'days' => 7,
    ],
];

// Após a alteração
return [
    'default' => 'default',
    'channels' => [
        'default' => [
            'driver' => 'daily',
            'path' => BASE_PATH . '/runtime/logs/hyperf.log',
            'level' => env('LOG_LEVEL', 'debug'),
            'days' => 7,
        ],
        // Adicione aqui o seu channel personalizado
    ],
];
```

4. A estrutura de configuração do `cache` foi alterada. Consulte [#7594](https://github.com/hyperf/hyperf/pull/7594).

```php
<?php
// Antes da alteração
return [
    'default' => [
        'driver' => RedisDriver::class,
        'packer' => PhpSerializerPacker::class,
        'prefix' => 'c:',
    ],
];

// Após a alteração
return [
    'default' => env('CACHE_DRIVER', 'default'),
    'stores' => [
        'default' => [
            'driver' => RedisDriver::class,
            'packer' => PhpSerializerPacker::class,
            'prefix' => 'c:',
        ],
    ],
];
```

5. Nova dependência ao usar `swow`.

`config/autoload/dependencies.php`

```php
<?php
use Hyperf\Contract\ResponseEmitterInterface;
use Hyperf\Engine\ResponseEmitter;

return [
    ResponseEmitterInterface::class => ResponseEmitter::class,
];
```

## Atenção

1. Se você já atualizou para o PHP 8.4, observe que os métodos `fgetcsv` e `fputcsv` agora exigem um valor padrão para o parâmetro `escape`.

```
fputcsv($fp, $fields) deve ser alterado para fputcsv($fp, $fields, escape: '')
fgetcsv($fp) deve ser alterado para fgetcsv($fp, escape: '')
```
